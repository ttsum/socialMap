## 项目目标

把团团团建设为一个可演示、可扩展的 AI-LBS 线下社交拼团小程序。
本轮范围：原生小程序前端 + 本地静态数据 + 完整操作路径，并推进后端与真实 AI 首期本机接入。
真实微信登录、真实加入/退出、定位、实时聊天、支付和生产上线另行推进。

## 本轮决策

- 将原规划遗漏的消息列表补成独立 `pages/messages`，群聊保留 `pages/chat`。
- 发布需求允许游客使用；收藏、加入和聊天使用明确标注的本地演示身份。
- 加入人数包含自己与同行伙伴，统一占用名额；不产生真实报名或费用。
- 地图为示意图，不请求真实定位；所有示例距离在界面说明来源。
- 需求解析是规则演示，时间和复杂表述须确认；偏好影响排序而非强制过滤。
- 保留本轮代码生成视觉，不提前引入后端或依赖图像服务。
- 打包忽略 docs、prototypes、tests、scripts、.qa 和原型脚本。
- 不把加入、退出、收藏、消息和聊天伪装成真实多人业务；本期 API 只负责检索、详情、解析和推荐。
