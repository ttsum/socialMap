# 团团团 AI 产品闭环说明

## 业务问题

线下活动信息分散，用户通常只能用自然语言描述“几个人、什么时候、预算多少、距离多远、喜欢什么”。直接把这段话交给传统筛选器会增加表达成本，直接让模型生成活动又会带来价格、名额和时间不可信的问题。

本项目的核心目标是降低需求表达成本，同时让推荐结果可解释、可追溯、可验证。

## 产品主流程

```text
自然语言需求
  → GLM 意图解析
  → Schema 校验与不确定字段标记
  → 用户确认/修改条件
  → 活动事实库硬过滤
  → 确定性排序
  → 基于事实字段生成推荐理由
  → 查看详情/加入拼团
```

没有匹配结果时，用户可以修改条件，或提交带具体地点的待审核需求。待审核需求不会自动生成正式活动。

## AI Workflow 边界

| 节点 | 负责内容 | 不负责内容 |
|---|---|---|
| 意图解析 | 人数、日期、时段、预算、距离、偏好和备注 | 生成活动价格、容量和地点 |
| 不确定性识别 | 标记缺失、模糊、否定和比较表达 | 替用户默默作出高风险判断 |
| 用户确认 | 修改 AI 解析出的条件 | 绕过确认直接推荐 |
| 推荐服务 | 城市、时间、容量、预算、距离硬过滤和排序 | 让模型决定事实数据 |
| 推荐解释 | 引用活动真实字段 | 编造评价、名额、路线或订单 |

因此项目准确定位为“LLM + 确定性推荐 Workflow”，不将其包装成自主 Agent。

## 可验证结果

- Mock 评测集：40 条样本。
- 评测字段：核心字段准确率、偏好 F1、不确定字段召回率、错误处理准确率、硬过滤违规数和解释事实一致性。
- 真实 GLM：通过独立受控命令执行；若外部网络超时，报告失败样本和阻塞原因，不将其写成模型质量结论。
- 工程证据：解析元数据、Prompt 版本、推荐版本、候选数量和命中数量均通过接口返回。
